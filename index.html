Observatorio

Observatorio es un proyecto desarrollado utilizando tecnologías como C#, ASP.NET MVC, SQL Server, CSS y Bootstrap.

Es una aplicación web desarrollada en ASP.NET Core con una arquitectura de dos partes: una API REST (con capas de lógica de negocio, aplicación e infraestructura) y un front-end MVC que la consume. Fue realizada en cumplimiento de los requerimientos académicos de la facultad.

Permite gestionar el inventario de telescopios, cámaras, oculares y monturas, y controlar los préstamos de equipos a los socios.

Cada socio puede planificar observaciones de objetos celestes sobre sus préstamos activos y consultar un ranking de los objetos más observados. Las observaciones cuentan con una evaluación asistida por inteligencia artificial.

El acceso se controla mediante autenticación con JWT y tres roles: el administrador gestiona equipos, socios y auditoría de préstamos, el coordinador registra préstamos y devoluciones, y el socio consulta sus préstamos y observaciones.

Los datos se almacenan en una base de datos SQL Server mediante Entity Framework Core.
